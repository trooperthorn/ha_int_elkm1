# Documentation index

- `protocol.md`: the RP binary programming protocol as reconstructed from
  ElkRP, with a citation for every rule and an Unverified section.
- `records.md`: byte layouts and bit meanings of every programming record.
- `operations.md`: running the service, importing an ElkRP database,
  connecting to a panel, where account files live.
- `security.md`: trust boundaries, what is enforced versus advisory, secrets
  handling, and why the shared-secret transport modes are not implemented.
- `design.md`: why a local web service, why specs drive everything, why the
  account is JSON.
- `decisions.md`: dated decisions with the alternatives rejected.
- `live_qualification.md`: the log of every exchange with a real panel.
- `app.md`: running as a Home Assistant app: the security layers, the passphrase,
  the audit log, coexistence with the integration, and the packaging in the
  `elk_programmer_app/` repository.
- `backlog.md`: open items, dated.
